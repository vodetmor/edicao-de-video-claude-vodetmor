# Máquina de Editar · núcleo do projeto "Edição de Vídeo com IA"

Este repositório guarda tudo para continuar o projeto em qualquer conta: o "cérebro" do Claude (`CLAUDE.md`), o jeito de trabalhar com o Vítor (`COMO-TRABALHAR-COM-O-VITOR.md`), memória, skills, histórico das conversas, biblioteca, motor de vídeo e os trabalhos.

- **Trocar de conta:** siga `MIGRACAO.md` (passo a passo para um Projeto novo no claude.ai ou para o Claude Code no PC).
- **Vídeos grandes:** estão em partes de 90 MB; rode `python backup/juntar_partes.py` na raiz para remontar.
- **Salvamento:** `backup/sincronizar.py` envia tudo para cá depois de cada entrega e todo dia às 23:37; o PC do Vítor puxa todo dia às 23:55.
- **Chaves e senhas** nunca ficam aqui: veja a lista para recriar em `MIGRACAO.md`.
