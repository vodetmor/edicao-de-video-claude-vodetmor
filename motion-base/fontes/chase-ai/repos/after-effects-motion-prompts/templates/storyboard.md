# Storyboard prompt template

Fill in the brackets and attach any brand/design references. This prompt commissions the plan and storyboard image; it stops before After Effects production.

```text
Act as a motion designer and art director. Develop a storyboard for an editable After Effects animation.

Product/topic: [NAME + ONE-SENTENCE DESCRIPTION]
Audience: [WHO IS WATCHING]
Main takeaway: [ONE THING THEY SHOULD UNDERSTAND]
Desired action: [CTA]
Format: [15 seconds, 16:9, 1920×1080, 30 fps]
Visual personality: [e.g. tactile clay/cardboard miniatures; bold editorial; playful paper cutouts]
Required copy: [EXACT WORDS, OR ASK YOU TO PROPOSE SHORT COPY]
References/assets: [ATTACHED FILES, LOGO, PALETTE, CHARACTER]

Create one coherent visual world and a simple story with a clear cause and effect. For a short promo, aim for 4–6 meaningful beats. Prefer connected views of the same scene when that suits the idea. Keep the same characters, objects, colors and product states across every frame.

Deliver:
1. A one-paragraph concept and concise proposed copy.
2. A timed beat sheet showing each beat's duration, framing, exact on-screen copy, action, transition, reading hold and sound cue. Total duration must match the brief.
3. One visual storyboard contact sheet using the available image-generation tool, with numbered frames and production captions outside the artwork. Keep important text large; preserve a separate exact-copy list in text.
4. An asset list separating native AE text/shapes from prepared imagery, with the parts that must move independently. Flag any image generation needed later.

Describe motion concretely: what moves first, what follows, where it settles and how it leads to the next beat. Give the main character purposeful anticipation and reactions. Plan audible background music and a few foreground effects if sound suits the brief.

Leave a readable closing hold. Do not start building in After Effects yet. Show the storyboard and plan for review.
```

If a preferred image tool is unavailable, have the agent return the complete image prompt and the written plan instead of claiming it generated the storyboard. A reference image or an already finished design can replace image generation.
