# Reference-video workflow

Supply a local MP4 or a link the agent can actually access. A URL alone does not guarantee video playback or frame access. Our reference analysis used sampled video frames and visible text; hidden prompts and source layers remained unknown.

## Analyze and storyboard

```text
Analyze the supplied reference video before building anything. I want to recreate its motion language in an editable After Effects project for [MY PRODUCT/TOPIC].

Keep close to its sequence, framing, pace, transitions and visual hierarchy. Replace the branding, copy and subject with [MY CONTENT]. Preserve [SPECIFIC FEATURES I LIKE].

Inspect the clip and sample enough frames around transitions to establish the action. Produce a time-coded shot/beat breakdown covering composition, text, object entrances, camera moves, easing character, transitions, reading holds and sound cues.

Separate what is directly visible from what you infer. Do not invent the creator's original prompt, source assets or exact easing/keyframe settings. Explain any part of the clip you could not inspect.

Turn that breakdown into a storyboard and exact-copy list for my version. List assets to prepare and which elements can be native AE layers. Match one representative design frame closely before expanding the plan.

Show the reference analysis, proposed storyboard and production prompt. Do not build in AE yet.
```

## Build after review

```text
Build the approved reference-based plan through the local Higgsfield After Effects bridge. Recreate the composition and motion as editable layers using our supplied/prepared assets and live text. Use the reference and approved beat sheet to compare key poses and transitions. Save a new AEP with assets and a rendered MP4, then correct visible discrepancies. State any remaining differences that matter. Do not use a cloud video-generation job.
```

This is an observed reference being reconstructed into a new AE scene. A rendered video does not reveal the creator's original editable layers, and the original prompt is not required for reconstruction.
