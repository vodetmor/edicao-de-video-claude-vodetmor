# Whiteboard Loop

A 12-second, 3840×2160, 30 fps native After Effects reconstruction of an eight-note collaboration board. The camera pushes into three ideas, follows annotations and cursors, pulls back to the full board and clears it for a loop. The delivered preview is silent.

Use [the copy-ready build prompt](build-prompt.md), [master board](references/master-whiteboard.png), [six-beat storyboard](references/six-beat-storyboard.png) and [shot plan with exact copy](references/shot-plan.md).

## Prompt provenance

[original-production-prompt.md](original-production-prompt.md) is the saved production prompt used for our build. The copy-ready version only normalizes its three supplied-file paths and adds a usage note.

This is **our executed adaptation**, informed by the visible design, prompt excerpts and motion in [Maddie’s whiteboard demo](https://x.com/madmadhere/status/2098498233035305427). It is not the creator’s recovered full prompt, original AE project or hidden timeline. The public promo is approximately 10 seconds; our approved storyboard deliberately retimes its observed order to 12 seconds.

The [image prompt record](image-prompts.json) preserves the prompts used to generate our master design and storyboard. The original creator video and software/chat screenshots are not included. The shot plan’s mention of a sampled source frame describes the analysis evidence; that source screenshot is not an attachment in this repository.

## Attachment authority

| File | What it controls |
|---|---|
| [master-whiteboard.png](references/master-whiteboard.png) | One consistent finished board design, note positions, colors, tilts and proportions |
| [six-beat-storyboard.png](references/six-beat-storyboard.png) | Shot order, framing and intended movement |
| [shot-plan.md](references/shot-plan.md) | Exact note wording, collaborator names, handwriting and interface labels |

Written copy takes priority over lettering in generated images. Keep all close-ups attached to the same board layout rather than rebuilding a different arrangement for each shot.

The final artwork uses native geometry and live text, including small editable vector portraits in place of the reference’s avatar photographs. The generated images are design guides, not flattened movie layers. The delivered project used Arial Regular, Arial Italic and Segoe Print; font files are not included.

The 77.15% incoming easing influence in the prompt is one starting parameter from the visible reference discussion. It is not a complete recovered speed curve; timing, velocity and other easing settings still require tuning in playback.
