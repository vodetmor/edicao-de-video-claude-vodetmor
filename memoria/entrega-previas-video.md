A thread accepts at most 24 attached outputs; after that post_message silently skips attachments. Vítor (2026-10-31) also could not open a 9 MB "celular" mp4 from the Library ("arquivo muito grande").
**How to apply:**
- For previews, publish a small Artifact player page (720x1280, crf 26, ~3-4 MB mp4 in `files`) and send the link. Jerônimo page: https://claude.ai/artifact/8mrv4xmRKXpBpAUpMk53mq (republish same scratchpad path or pass url to add versions).
- Archive old versions on his PC: folder `C:\Users\vitor\OneDrive\Desktop\Maquina de Editar\clientes\<cliente>\previas\` via device_commit_files (max 25 MB per file read, 100 MB per call). Code goes to GitHub as usual ([[backup-portatil]]).
- He also said replies were "escrito muito grande": keep thread messages short.
